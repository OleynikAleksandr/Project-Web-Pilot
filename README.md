# Project Web Pilot

Локальное приложение для работы с проектами через настоящий ChatGPT Web: слева workspace, план и состояние подключения, справа встроенный Chromium. Приложение подготавливает локальные инструменты и само отправляет стартовое сообщение, чтобы агент получил контекст выбранного проекта.

**Состояние на 11.09.2026:** создан workspace и подготовлен первоначальный план. Код нового приложения ещё не написан. В текущей сессии выполняется только документальная подготовка. Название пользователя — Project Web Pilot; Project Workbench было предложением, не итоговым названием.

## Начало новой сессии

Сначала прочитать [инструкцию продолжения](docs/WORKFLOW_START.md), затем выполнить `./scripts/workflow recover --format text`, если актуальный packet не доставлен. Единственный активный план — [.harness/plans/todo-plan.md](.harness/plans/todo-plan.md). Не начинать обсуждение идеи заново: решения уже записаны в [docs/DECISIONS.md](docs/DECISIONS.md).

Первая реализация должна проверить небольшую сквозную цепочку: **выбранный workspace → готовые MCP и tunnel → встроенный ChatGPT → автоматически отправленное сообщение → recover → ACK → видимое подтверждение**. Полное объединение кодовых баз следует после реальной проверки этой цепочки.
