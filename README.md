# Project Web Pilot

Приложение для macOS и Windows: в одном окне слева ваши локальные проекты, их чаты и текущий план, справа ChatGPT Web во встроенном браузере. Модель работает через ваш веб-аккаунт ChatGPT, без модельных API. Доступ агента к файлам и командам этого компьютера даёт локальное подключение «Codex App Server Local Mac» / «Codex App Server Local Windows» через защищённый туннель. Проекты ведутся с Workflow Kit (план, задачи, коммиты).

Версия **0.6.98**: Workflow Kit 1.6.0, Electron 44.5.1, встроенный Node 24.21.0. Версию установленного приложения показывает меню «О Project Web Pilot».

## Требования
- macOS на Apple Silicon или Windows 10/11 x64. Windows на ARM использует эмуляцию x64, отдельной сборки нет.
- Аккаунт ChatGPT. Если его нет, мастер первого запуска подскажет, как зарегистрироваться.
- Для подключения к файлам: доступ к разделу Tunnels в OpenAI Platform (создать туннель — права Tunnels Read + Manage, работать — Read + Use), личный API key этой организации и developer mode в ChatGPT. В управляемом пространстве доступ выдаёт администратор; наличие аккаунта этих возможностей не гарантирует.
- Установленный Codex: на Mac — Codex CLI или приложение ChatGPT, на Windows — Codex CLI. Web Pilot использует его только как локальный исполнитель инструментов, без модельных запросов.
- На Mac — Apple Command Line Tools (Git). Если их нет, мастер предложит установку.
- Интернет при первой подготовке: загружаются Python 3.13 и пакеты исполнителя (на Mac также tunnel-client).
- Отдельно ставить Node, Python, браузер или приложение ChatGPT не нужно. В поставку входят Node и uv; Windows-поставка дополнительно содержит tunnel-client, ripgrep и MinGit, поэтому системный Git на Windows не нужен.

## Установка

### macOS
1. Распакуйте macOS ZIP и откройте Project Web Pilot.app.
2. Если приложение запущено не из «Программ» и проектов ещё нет, оно предложит переместиться в «Программы» и перезапустится оттуда. Если там уже есть Project Web Pilot, замена произойдёт только после подтверждения; проекты и настройки сохранятся. Можно отказаться — приложение продолжит работу из текущей папки.
3. Системные подтверждения macOS проходите штатно; отключать защиту системы не нужно.

### Windows
1. Распакуйте **всю** папку Windows ZIP на локальный диск и запускайте `Project Web Pilot.exe` из неё. Не запускайте программу из архива и не переносите EXE отдельно от папки `resources`. Установщика нет, права администратора не нужны.
2. Если Codex CLI не установлен, мастер покажет команду для PowerShell:
   `powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
   (другой способ — `npm install -g @openai/codex`). После установки нажмите «Проверить и продолжить»; приложение закрывать не нужно.

## Первый запуск
Без проектов открывается экран «Начнём работу». Он ведёт по пяти шагам; вернуться к нему можно кнопкой «Начальная настройка» внизу сайдбара.
1. **ChatGPT.** Справа открывается страница входа. Первое открытие может занять до двух минут — повторять нажатие не нужно. Войдите или зарегистрируйтесь прямо в окне Web Pilot. Если сайт не открылся, нажмите «Скопировать диагностику» и передайте отчёт разработчику: в нём нет текста бесед, cookies и ключей.
2. **Подготовка компьютера.** Web Pilot сам готовит локальные компоненты и запускает локальный MCP. На Mac без Command Line Tools нажмите «Установить компонент Apple» и подтвердите установку в окне Apple — она может занять десятки минут. Если окна не видно, сверните Web Pilot. Затем нажмите «Проверить и продолжить».
3. **Подключение к файлам (туннель).** Для каждого компьютера создаётся отдельный туннель. «Открыть Tunnels в OpenAI Platform» → создайте туннель и свяжите его со своим пространством ChatGPT → Copy tunnel ID. Затем «Открыть API keys» → в той же организации Create new secret key → Copy полного ключа `sk-…`. Web Pilot сам подхватывает скопированные ID и ключ; иначе используйте «Вставить ID туннеля» и «Ввести API key» — они открывают системное окно ввода. Ключ хранится только на этом компьютере и не передаётся модели.
4. **Подключение в ChatGPT.** Создаётся вручную, само не появляется: Plugins в основном сайдбаре ChatGPT → «+» → имя **Codex App Server Local Mac** или **Codex App Server Local Windows** → Connection: Tunnel → туннель **этого** компьютера → No authentication → дождитесь списка инструментов. Существующее правильное подключение пересоздавать не нужно; на Windows прежнее «Codex Local Windows MCP» с тем же туннелем достаточно обновить кнопкой Refresh. Если нет кнопки «+», проверьте Settings → Security and login → Developer mode.
5. **Первый проект.** «Создать новый проект» или «Добавить существующую папку». В новом чате добавьте подключение этого компьютера через меню инструментов и попросите агента прочитать и изменить тестовый файл в папке проекта: доступ подтверждает сохранённый файл.

### Разрешения
- Подтверждения действий агента настраиваются в ChatGPT: Settings → Plugins → ваше подключение → Permissions. Режимы: Always ask, Allow read actions, Allow low-risk actions (по умолчанию), Allow all actions. Allow all actions позволяет агенту менять файлы без повторных вопросов в пределах правил ChatGPT. Режим выбираете вы; Web Pilot его не меняет.
- Это не системные разрешения macOS. Для снимков экрана macOS отдельно запрашивает запись экрана (Screen Recording); микрофон и геолокация для сайта ChatGPT разрешаются отдельно, камера не используется. Управление мышью и клавиатурой через MCP не предусмотрено.

### Канал подключения
В «Настройках» (шестерёнка внизу сайдбара) → «Подключение ChatGPT» выбирается Secure MCP Tunnel (по умолчанию) или VPS — свой сервер, доступный только после его настройки на этом компьютере. Подключение (плагин) в ChatGPT для выбранного канала включает пользователь: Web Pilot плагины в ChatGPT не переключает. Подробно — [runtime-lifecycle](docs/modules/runtime-lifecycle.md).

## Обновление
1. Полностью завершите Web Pilot (на Mac — ⌘Q).
2. macOS: замените приложение в «Программах» новой версией. Windows: распакуйте новую поставку целиком в отдельную папку и запускайте `Project Web Pilot.exe` оттуда.
3. Откройте приложение. При запуске Web Pilot сам обновляет и перезапускает фоновые службы. Вход в ChatGPT, настройки, проекты, сессии и туннель сохраняются.
4. Если в новой версии изменился набор инструментов, откройте подключение в ChatGPT и нажмите Refresh: ChatGPT хранит прежний список инструментов.

На Windows, где раньше работал прежний сервер инструментов Web Pilot, первая подготовка новых служб (при запуске мастера или открытии проекта) останавливает его и снимает его автозапуск. Туннель и ключ переносятся автоматически, перенастраивать их не нужно; в прежнем подключении ChatGPT достаточно нажать Refresh.

## Фоновые службы
Локальный MCP и туннель запускаются при входе в систему и продолжают работать после закрытия окна Web Pilot; выключение компьютера их завершает. Открывать Web Pilot для этого не нужно.
- macOS: LaunchAgent `com.oleynik.WebPilotCodexExecutor` (`~/Library/LaunchAgents`).
- Windows: автозагрузка текущего пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `ProjectWebPilotCodexExecutor`, программа `pythonw`); видна в Диспетчере задач на вкладке «Автозагрузка».

## Где лежат данные
| Что | macOS | Windows |
|---|---|---|
| Профиль ChatGPT (вход), `settings.json`, список проектов и сессий `workspaces.json`, диагностика (`diagnostics/`, `diagnostics.jsonl`) | `~/Library/Application Support/Project Web Pilot` | `%APPDATA%\Project Web Pilot` |
| Локальный исполнитель: его копия, Python и инструменты, профиль туннеля, ключ туннеля | `~/Library/Application Support/WebPilotCodexExecutor` | `%LOCALAPPDATA%\WebPilotCodexExecutor` |

- Ключ туннеля лежит в `private` каталога исполнителя: на Mac — файл с доступом только владельцу, на Windows — зашифрован для текущего пользователя (DPAPI). Модели, в Git и в диагностику ключ не попадает.
- Диагностика не записывает текст бесед, cookies и ключи.
- Проекты хранятся в папках, которые выбрали вы; удалить проект с диска можно только из окна архива («Настройки» → «Архив…» → «Удалить с диска…») после ввода точного имени проекта; облачные чаты ChatGPT при этом не удаляются ([project-archive](docs/modules/project-archive.md)).
- Папки прежнего локального сервера Web Pilot не удаляются автоматически: на Mac — `~/Library/Application Support/CodexLocalMac`, на Windows — `%LOCALAPPDATA%\CodexLocalWindows` (и папка, которую вы для него выбирали). В них лежит прежний ключ туннеля; туннель из них переносится один раз при первой подготовке служб, после этого их можно удалить вручную, если возврат к прежним версиям не нужен.

## Известные ограничения
- Windows-версия с исполнителем Codex App Server на настоящей Windows пользователем ещё не проверялась; первый запуск на чистой macOS с этим исполнителем — тоже.
- Изменения разметки ChatGPT Web могут потребовать обновления Web Pilot.
- Восстановление контекста после внутреннего сжатия беседы (compact) в ChatGPT не заявляется: подтверждённого сигнала об этом нет.

## Из исходников
Клон репозитория содержит исходники, а не готовое приложение. Нужны Node.js `^24.21.0` и npm:
```bash
npm ci
npm start
npm test
npm run smoke
npm run check --prefix packages/workflow-kit
```
Сборка пакетов (`npm run build`) выполняется только в задаче выпуска — [release](docs/modules/release.md).
