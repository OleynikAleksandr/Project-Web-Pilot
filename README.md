# Project Web Pilot

Локальный macOS-прототип 0.3: слева проекты и состояние контекста, справа настоящий ChatGPT Work во встроенном Chromium. При открытии нового чата приложение получает полный контекст выбранного проекта и автоматически отправляет его первым сообщением. Агент коротко подтверждает восстановление и описывает назначение и текущее состояние проекта.

## Запуск и первый тест

Откройте [Project Web Pilot.app](<.harness/runtime/build/Project Web Pilot-darwin-arm64/Project Web Pilot.app>). Это локальная сборка для этого Mac с Apple Silicon. Вход в ChatGPT и сохранённые чаты переносятся автоматически. Перед обновлением формата настроек создаётся локальная резервная копия.

1. Дважды нажмите на workspace слева или нажмите стрелку рядом с ним — раскроется список сессий.
2. Нажмите нужную сессию: откроется именно её чат. Название, номер и дата помогают различать разговоры.
3. «Новый чат для проекта» добавляет ещё одну сессию в дерево. Прежние остаются доступны. Полный контекст передастся автоматически, агент коротко опишет проект.
4. Закройте и снова откройте приложение: список, выбранная сессия и раскрытие workspace сохранятся. Повторного стартового сообщения не будет.

Одинарный клик по workspace открывает выбранную в нём сессию; двойной клик только раскрывает или сворачивает дерево. Можно также использовать стрелки вправо/влево на выделенной строке.

Первый ответ не требует вызова инструментов: весь пакет уже находится в сообщении. Для дальнейших действий с файлами используйте режим Work с подключённым Codex Local Mac. «Открыть папку проекта» принимает существующую папку с Workflow Kit; создание проекта с нуля пока не реализовано.

«Обновить контекст» получает и отправляет новый полный пакет. Старые чаты версии 0.1 открываются как сохранённые сессии; обновление выполняется только по этой кнопке либо в новом чате. При изменении плана интерфейс показывает устаревший пакет. Если в поле есть черновик или ChatGPT отвечает, автоматический старт ждёт. При неизвестном результате Send приложение проверяет сообщение, прежде чем разрешить новую отправку.

Настройка пути к существующему Codex Local Mac находится в «Подробностях подключения». Там же видны размер, версия и время переданного пакета. Закрытие приложения сохраняет общие локальные службы для других чатов.

## Границы прототипа

Дерево содержит сессии, созданные и сохранённые в Web Pilot. Из версии 0.2 переносится та связь с чатом, которую она сохранила для workspace. Более ранние связи, уже заменённые старой версией, автоматически из веб-истории не импортируются.

- Использует веб-аккаунт ChatGPT и существующий Codex Local Mac на этом компьютере; самостоятельный MCP ещё не включён в поставку.
- Поддерживает выбор подготовленных проектов, связанные чаты и отображение текущей задачи. Создание папок и установка Workflow Kit из сайдбара остаются следующим этапом.
- Передача контекста выполняется при старте или явном обновлении. Автоматическое восстановление после compact не реализовано.
- Локальная arm64-сборка без публикации, установщика, нотариализации и Windows-проверки. Изменение разметки ChatGPT может потребовать обновления адаптера.

Результаты реального запуска, проверок и ограничения описаны в [VERIFICATION](docs/VERIFICATION.md). Пользовательская приёмка остаётся за пользователем.

## Разработка

Требуются Node.js 22.17.0 или совместимый, npm и настроенный Codex Local Mac.

```bash
npm ci
npm start
npm test
npm run smoke
npm run build
```

Проверки: 33 Node tests и интеграционный Electron smoke с полным пакетом 75 КБ. Smoke также проверяет две сессии, выбор предыдущей и раскрытие дерева. Использует отдельный TEST FIXTURE и не заменяет проверку настоящего ChatGPT.

Профиль Chromium, настройки и привязки находятся в `~/Library/Application Support/Project Web Pilot`, вне Git. Полный подготовленный текст хранится локально для безопасного возобновления отправки. Диагностика содержит только переходы состояния и метаданные; содержимое сообщений, cookies и ключи туда не записываются.
