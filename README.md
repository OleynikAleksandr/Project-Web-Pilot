# Project Web Pilot

Первый рабочий macOS-прототип: слева проекты и состояние контекста, справа настоящий ChatGPT Work во встроенном Chromium. Приложение открывает подготовленную папку, запускает локальные инструменты, само отправляет стартовое сообщение и проверяет подтверждение от агента.

На 11.09.2026 реальный сценарий проверен на WF001: сообщение отправлено автоматически, агент получил контекст через MCP и вернул ACK, сайдбар показал «Контекст подтверждён». Повторный запуск сохранил вход и чат без дубля сообщения. Прототип готов к пользовательскому тестированию; приёмка ожидается.

## Запуск и первый тест

Откройте [Project Web Pilot.app](<.harness/runtime/build/Project Web Pilot-darwin-arm64/Project Web Pilot.app>). Это локальная сборка для этого Mac (Apple Silicon); приложение уже запускалось с вашим входом в ChatGPT.

1. Для проверки с чистого чата выберите WF001 слева и нажмите «Новый чат для проекта». В ChatGPT должен быть выбран режим Work с подключённым Codex Local Mac.
2. Дождитесь ответа агента и статуса «Контекст подтверждён». Копировать или отправлять стартовый текст вручную не нужно.
3. Продолжите разговор справа либо закройте и снова откройте приложение: папка и её чат сохранятся.

«Открыть папку проекта» принимает существующую папку с Workflow Kit. Создание проекта с нуля пока не реализовано. «Обновить контекст» после подтверждения отправляет новый запрос восстановления; «Проверить статус» во время ожидания лишь проверяет результат.

Если в поле есть ваш черновик или ChatGPT отвечает, автоматический старт подождёт. Если ACK не пришёл, проверьте ответ Work и доступность Codex Local Mac. Настройка пути к существующему runtime находится в «Подробностях подключения». Закрытие приложения сохраняет общие локальные службы для других чатов.

## Границы прототипа

- Использует ваш веб-аккаунт ChatGPT и существующий Codex Local Mac на этом компьютере; автономный MCP ещё не включён в поставку.
- Поддерживает выбор подготовленных проектов, связанные чаты и отображение текущей задачи; создание папок и установка Workflow Kit из сайдбара остаются следующим этапом.
- Подтверждён стартовый запрос и повторное открытие. Внутренний SessionStart и автоматический compact ChatGPT не подключены.
- Это локальная arm64-сборка без публикации, установщика, нотариализации и Windows-проверки. Разметка ChatGPT может измениться и потребовать обновления адаптера.

Для фидбэка полезны удобство сайдбара, понятность статусов, повторный запуск и работа с другим подготовленным проектом. Следующий объём выбирается после вашей проверки.

## Разработка

Требуются Node.js 22.17.0 или совместимый, npm, установленный Codex Local Mac и настроенное подключение в аккаунте ChatGPT.

```bash
npm ci
npm start
npm test
npm run smoke
npm run build
```

Проверки: 28 Node tests и интеграционный Electron smoke. Smoke использует отдельный TEST FIXTURE и не заменяет реальный опыт. Доказательства реального запуска и ограничения описаны в [VERIFICATION](docs/VERIFICATION.md).

Профиль Chromium, настройки и привязки хранятся в `~/Library/Application Support/Project Web Pilot`, вне Git. Диагностика приложения содержит переходы состояния и идентификаторы; challenge, cookies и ключи туда не записываются.
