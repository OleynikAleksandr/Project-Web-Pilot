# Продукт

## Идея

Project Web Pilot — самостоятельное локальное приложение, объединяющее подготовку проектов Project Workflow Kit и доступ веб-агента к компьютеру через Codex Local Mac. Пользователь работает в одном окне: слева собственный сайдбар, справа настоящий ChatGPT Web внутри встроенного Chromium.

Пользователь прямо выбрал встроенный Chromium. Использование внешнего Chrome, его текущего профиля или отдельно открытого Safari не соответствует этому решению. Вход в ChatGPT выполняется пользователем в профиле нового приложения и сохраняется между запусками.

Модель работает через имеющийся веб-аккаунт ChatGPT. Приложение не вызывает модельные OpenAI API и не запускает отдельного кодирующего агента. Доступ к локальным файлам и командам обеспечивает MCP. Транспортный ключ Secure MCP Tunnel не является ключом для генерации ответов и не должен попадать в чат, документы или Git.

## Согласованный пользовательский сценарий

1. Пользователь открывает приложение и выбирает workspace слева.
2. Приложение определяет папку проекта и связанный с ней чат, подготавливает MCP и подключение.
3. Справа открывается ChatGPT; после готовности поля ввода приложение вызывает собственный локальный стартовый сценарий и отправляет подготовленное сообщение с путём проекта и задачей.
4. Агент через MCP получает актуальный пакет контекста, подтверждает его и сообщает пользователю, какой проект и состояние восстановлены.
5. Сайдбар показывает подтверждённый проект и версию плана. Пользователь продолжает обычный диалог.

Подробный порядок, параметры и обработка ошибок находятся только в [CONTEXT_DELIVERY.md](CONTEXT_DELIVERY.md). Остальные документы ссылаются на этот контракт.

## Полная цель продукта

Сайдбар должен постепенно получить создание нового workspace, подключение существующего, недавние проекты, открытие связанного чата, состояние плана и локальных служб. При создании папки устанавливаются инструкции, структура документации, план и необходимые скрипты Workflow Kit. При подключении существующей папки сохраняются её файлы, план, история и hooks.

Смысл объединения — один рабочий интерфейс и согласованный жизненный цикл. Источники плана, Git-состояния и recovery остаются в ядре Workflow Kit. Агент выполняет поручения пользователя через локальный MCP. Сайдбар отображает факты ядра и подтверждения, не исправляет статусы Markdown самостоятельно.

## Первый проверочный scope

На 11.09.2026 macOS-прототип реализован и собран на компьютере пользователя. Он использует выбранные существующие workspace с Workflow Kit, существующее подключение Codex Local Mac и встроенный ChatGPT. Реальная цепочка проверена на WF001; история задач находится в единственном активном плане.

Проверены реальный вход, доступность MCP, автоматическая отправка, получение пакета, ACK и подтверждение в чате/сайдбаре. Повторный запуск сохранил чат без дубля. Граничные ошибки дополнительно проверены в fixtures; доказательства и ограничения — VERIFICATION. Пользовательская приёмка ожидается; массовый перенос двух исходных приложений не выполнялся.

Для первого опыта допустим явно настроенный путь к существующему Codex Local Mac. Это временная зависимость прототипа, а не самостоятельная поставка конечного продукта. В дальнейшем перенос нужных модулей выполняется в новый репозиторий с фиксацией происхождения.

## Следующее расширение

После принятия прототипа уточнить задачи по переносу ядра Workflow Kit, созданию и подключению проектов из сайдбара, отображению плана и самостоятельной поставке локального runtime. Переносимость на Windows учитывается при выборе оболочки, но отдельная Windows-версия и её физическая проверка не входят в первый macOS-прототип. Эти направления не образуют второго активного TODO: конкретные задачи добавляются управляемой командой после уточнения объёма.

## Граница compact

Пользователь хочет восстановление и после автоматического compact. Отправка через поле ввода решает доставку сообщения, но не обнаружение внутреннего события ChatGPT. В доступном Web Work подключении автоматические hooks ранее не были подключены. Новый Chromium сам по себе этого не меняет.

В первом scope подтверждается стартовый сценарий. Восстановление перед следующим пользовательским запросом обсуждалось как возможная альтернатива; оно не утверждено как обязательное действие на каждом ходе. Надёжный сигнал compact остаётся отдельной исследовательской задачей, а не скрытым обещанием прототипа.

## Приёмка

Пользователь видит одно окно со встроенным ChatGPT, сам выбирает папку и получает автоматический старт без копирования промпта. Агент и сайдбар показывают совпадающие факты выбранного проекта. Переключение проекта не перенаправляет работающий чат в другую папку. Ошибки отправки, подключения и подтверждения различаются. Сборка, HTTP-ответ или ручной вызов хука отдельно не считаются этой приёмкой.
