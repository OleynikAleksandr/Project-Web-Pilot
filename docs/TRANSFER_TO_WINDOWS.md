# Перенос на Windows 10/11

Текущая поставка — **Project Web Pilot 0.6.43, Windows x64**, собранная вместе с macOS arm64 из одного репозитория. Исходный проект Win Project Web Pilot не нужен.

## Файл для переноса

`~/Downloads/WebPilot-0.6.43/Project-Web-Pilot-0.6.43-Windows-x64.zip`

- Project-Web-Pilot-0.6.43-macOS-arm64.zip: 181062445 bytes; SHA-256 `e7eda01af7ca83b72fed55cf9d1dd8f5108cc50ff5d05d2389bbe7c2aaccf368`.
- Project-Web-Pilot-0.6.43-Windows-x64.zip: 316334779 bytes; SHA-256 `7b3c0e12a509ee2cca688e33460ae5768a0eeb0b76410f39f83250cfda08f66c`.

Контрольные суммы, инструкция и общий manifest лежат рядом. Полностью распакуйте ZIP на локальный диск Windows; запускайте `Project Web Pilot.exe` из полученной папки. Не переносите один EXE отдельно от resources. Для обновления завершите старое приложение и распакуйте новую поставку в отдельную папку; данные аккаунта и проектов в пользовательском профиле сохраняются.

## Первый запуск

Мастер «Начнём работу» доступен повторно через «Начальная настройка» внизу сайдбара и настройку подключения Windows.

1. Войти в ChatGPT на странице справа.
2. Дождаться подготовки комплектных Python, Git, MCP и tunnel-client. Отдельная установка системного Git/Node не требуется. Для загрузки зависимостей может потребоваться интернет.
3. На подшаге «ID туннеля» нажать «Открыть Tunnels в OpenAI Platform». Создать отдельный туннель для этой Windows и связать его с нужным пространством ChatGPT. Нажать Copy tunnel ID. Web Pilot примет tunnel_id автоматически; для ручного ввода нажать «Вставить ID туннеля», вставить Ctrl+V в открывшееся системное окно и подтвердить. Пустой буфер до открытия окна не вызывает ошибку; отмена оставляет первый шаг.
4. На следующем подшаге «Личный API key» нажать видимую кнопку «Открыть API keys в OpenAI Platform». В той же организации выбрать Create new secret key, задать имя Web Pilot, выбрать проект, если сайт его запрашивает, и подтвердить создание. Нажать Copy в окне созданного ключа: нужен полный секрет sk-…, а не имя ключа или ID туннеля. Web Pilot подхватит его автоматически. При необходимости нажать «Ввести API key», вставить Ctrl+V в защищённое системное поле и подтвердить. ID повторно не вводится. Для работы нужны права аккаунта Tunnels Read + Use в организации туннеля.
5. В ChatGPT Plugins добавить или проверить **Codex Local Windows MCP**, Connection: Tunnel, выбрать туннель этой Windows, No Auth. Работающая служба туннеля ещё не доказывает выбор правильного подключения в ChatGPT; одно имя плагина тоже недостаточно.
6. Создать первый проект на локальном диске гостя, выбрать расположение папок и Chat/Work. Полный контекст отправляет приложение первым сообщением.

Ключ скрыт и сохраняется через DPAPI текущего пользователя, не попадает в renderer/diagnostics/argv. Туннель и подключение Mac остаются отдельными. Установленные совместимые компоненты переиспользуются. Отмена или неверные данные до сохранения не меняют конфигурацию; ошибка позволяет повторить шаг.

## Доказательства и самостоятельная проверка

Оба ZIP, версии и упакованные src/resources сверены. Автоматические проверки выполнены на основном Mac. Пользователь сам проводит все дальнейшие проверки; агент не запускает UTM и не использует Computer Use по прямому поручению 18.09.2026.

Windows 11 ARM64 в UTM запускает x64-приложение через эмуляцию; это отдельный результат от нативной Windows x64. Запуск и вход в 0.6.40 подтверждены пользователем; в 0.6.41 мастер появился, повтор подготовки позволил перейти к туннелю. Первичный сбой подготовки не диагностирован. В 0.6.42 пользователь обнаружил, что кнопка ID не открывает окно; это исправлено в 0.6.43. Новый проход 0.6.43 и работа MCP пока не приняты.

Оставшийся пользовательский результат: пройти мастер, подключить правильный туннель, создать проект, получить краткое восстановление контекста, попросить агента прочитать/изменить тестовый файл только в гостевом проекте и проверить сохранение готовности после перезапуска. Реальные ключи, профили браузера и проекты с Mac не переносить в тестовый архив.

Если копирование большого ZIP через общую папку UTM сообщает 0x800700DF, это проблема переноса WebDAV, ранее наблюдавшаяся для 301 МБ, а не запуска приложения. Не считать успешно переданной неполную копию; сверить SHA-256.

Scope выпуска — windows-onboarding-033 собственной сессии; планы 031 и 032 не изменяются. Реестр наблюдений — docs/CLEAN_INSTALL.md, контракт — docs/modules/first-run-onboarding.md, детали выпуска — docs/RELEASE.md.
