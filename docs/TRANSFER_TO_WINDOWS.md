# Перенос на Windows 10/11

Актуальная Windows-сборка: **Project Web Pilot 0.6.26, x64**. Архив `Project-Web-Pilot-0.6.26-Windows-x64.zip` подготовлен в `.harness/runtime/releases/0.6.26/` на Mac. SHA-256 архива: `fda8e51583060873a60ca67903271d77c9dcb66bf437a48fa4befc627a7e59f3`. Все исходники по-прежнему принадлежат одному репозиторию `OleynikAleksandr/Project-Web-Pilot`; отдельный исходный проект Win Project Web Pilot больше не нужен.

1. Перенесите ZIP на Windows и полностью распакуйте его в новую папку на локальном диске.
2. Закройте старый Web Pilot. В распакованной папке `Project Web Pilot-win32-x64` запустите `Project Web Pilot.exe`.
3. Сохраняйте вместе EXE, папку `resources` и остальные файлы. Запуск из просмотра ZIP или перенос только EXE не является установкой полной сборки.
4. Откройте нужный проект. При ошибке подготовки запустите «Доктор проекта» в Settings или с экрана ошибки; затем проверьте прежнюю и новую сессию.
5. Если ошибка повторится, сохраните полный текст сообщения и версию приложения. NODE_MISSING, NODE_TOO_OLD и NODE_START_FAILED теперь различают отсутствие Node, старую версию и отказ запуска.

Portable Node.js 22.17.0 включён; отдельно устанавливать Node для этой готовой поставки не требуется. Исправление очищает внешние NODE_OPTIONS/NODE_PATH только у дочерних Windows-процессов. Существующие проекты и пользовательские данные не нужно переносить в папку приложения или удалять.

Контрольные суммы обеих поставок находятся рядом в `SHA256SUMS.txt`; файл проверен после упаковки. Для 0.6.26 также подтверждена целостность ZIP, версия 0.6.26 внутри Windows `app.asar` и совпадение затронутого sidebar UI с source.

Сборка и автоматические проверки пройдены на Mac; реальный запуск на Windows 10 ожидает пользовательской проверки. Проектный scope остаётся активным до принятия.
Редактор цветов: Settings → «Цвета чата…». В отдельном перемещаемом окне выберите фон чата, плашку пользователя, фон поля ввода и цвета текста обеих сторон; изменения видны сразу и сохраняются автоматически. «Вернуть оформление ChatGPT» снимает все пять переопределений. Копия архива на Mac для переноса: `~/Downloads/WebPilot-0.6.26/`.
