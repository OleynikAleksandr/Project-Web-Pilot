# Перенос на Windows 10/11

1. Закройте приложение на Mac перед копированием.
2. Скопируйте **всю** папку `Win Project Web Pilot`, включая скрытые `.git` и `.harness`.
3. На Windows не запускайте exe из сетевого/архивного preview: сначала разместите папку на локальном NTFS-диске.
4. Запустите `RUN_WINDOWS.cmd` или `windows-app\Project Web Pilot.exe`.
5. Если SmartScreen показывает неизвестного издателя, это ожидаемо для текущей неподписанной test build; проверяйте, что файл взят именно из этой папки.
6. После старта откройте Settings → «Локальные инструменты Windows», дождитесь подготовки runtime, затем настройте tunnel в отдельной консоли и нажмите «Проверить».
7. В текущем чате сообщите точный результат первого запуска. Если появится ошибка, не переустанавливайте вручную компоненты до фиксации текста/скриншота ошибки.

Актуальный Windows distribution: Project Web Pilot 0.6.2. Если на компьютере уже работает совместимый настроенный Codex Local Windows MCP/tunnel, приложение переиспользует его; повторно настраивать tunnel не нужно. Bundled runtime остаётся fallback для компьютера без совместимой установки.
