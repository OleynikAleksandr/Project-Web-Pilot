# Совместимость интерфейса ChatGPT — 0.6.48

Владелец: Workspace & Sessions. Контракт утверждён пользователем 25.09.2026 по результатам реального аудита 0.6.47.

Facade `chatgpt-dom.mjs` читает только видимый DOM: composer, send/stop, режим, сообщения, служебные блоки. Общие селекторы сериализуются в изолированный Chromium; ни cookies, ни page internals, ни модельные API не используются. Код поддерживает прежние и новые атрибуты. Отсутствие подтверждённого режима блокирует передачу, а не угадывается по URL. `/` и `/work/` — точки входа, кнопки могут изменить режим без навигации. Сохранённая неопределённая отправка не повторяется автоматически.

Границы: фильтр скрывает только опознанные служебные строки, не ответы, файлы и запросы разрешений. Цвета используют те же semantic message selectors. Прокрутка учитывает обычный и обратный поток, прекращает следование при ручном чтении и не создаёт цепочку scroll → scroll. UI завершает свои renderer-процессы, но не останавливает независимые MCP/tunnel. Их пользовательский автозапуск действует после входа в ОС; до входа личный профиль недоступен.

Приёмка: Node regression и Electron fixture обязательны; реальный DOM и Windows-проверки фиксируются отдельно. Успешная сборка не подтверждает доставку контекста в реальном чате.

## Итог реализации 25.09.2026

Контракт реализован в локальном 0.6.48. Живые новые Chat и Work получили полный пакет и подтвердили восстановление; hide/show карточки после MCP вызова проверен. Выявленный при этом transient `local-chatgpt` URL поддержан отдельной регрессией. Сборка сверяет исходники и оба ZIP; native Windows и reboot/login остаются непроверенными. Доказательства — `docs/VERIFICATION.md`, доставка — `docs/RELEASE.md`.
