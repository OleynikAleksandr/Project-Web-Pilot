## Принятое техническое направление

Electron с WebContentsView используется для собственного Chromium и интерфейса. В T004 выбраны Electron 44.3.0 и @electron/packager 20.3.0; полный профиль записан в ARCHITECTURE. Смена продуктового решения о встроенном браузере требует обсуждения.

Для первого прототипа приложение само запускает существующий MCP и tunnel до отправки сообщения. Первое сообщение просит агента получить пакет через уже реализованные MCP-инструменты, а не содержит вручную скопированную устаревающую версию всего контекста. Сайдбар получает подтверждение из status. Это проектное решение на основе обсуждённого сценария.

Первый этап — macOS; модель вызывается веб-сервисом ChatGPT. Полный перенос двух кодовых баз и Windows-поставка откладываются до проверки основного сценария.

## Не подтверждено

- Устойчивость адаптера поля ввода ChatGPT при изменениях страницы.
- Получение достоверного события автоматического compact из Web Work.
- Автоматическая отправка контекста перед каждым пользовательским сообщением.
- Перенос контекстных инструментов на Windows: в исходном Windows-комплекте нет macOS-модуля context_probe.py.
