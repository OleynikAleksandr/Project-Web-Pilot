# Архив проектов

## Пользовательский контракт

Шестерёнка справа от «Подробностей подключения» открывает настройки с архивом workspace. Архивирование из меню проекта убирает его из активного списка и сохраняет папку, план, все сессии и выбранный разговор. Архив — состояние Web Pilot; статусы Workflow Kit не меняются.

В настройках пользователь выбирает архивный проект. «Вернуть в активные» возвращает его дерево без автоматической отправки нового контекста. «Удалить с диска…» открывает отдельное подтверждение с точным путём, размером и числом локальных сессий. Удаление должно быть явно подтверждено и затрагивать только выбранную папку и её локальные записи. Чаты в аккаунте ChatGPT остаются: пользователь исключил их удаление из задачи.

## Хранение

SchemaVersion 3 добавляет archivedAt к workspace. Старые форматы 1 и 2 мигрируют с точной локальной резервной копией. Все существующие проекты начинают активными. Архив сохраняет sessions[], selectedSessionId, expanded, названия, URL и попытки отправки. При архивации выбранного проекта selectedWorkspace очищается; запоздалые обновления его сессий отклоняются.

Изменения настроек сериализованы и становятся видимыми только после успешного атомарного сохранения. Ошибка записи сохраняет прежнее состояние. Архивирование и возврат не требуют доступности папки; открытие после возврата выполняет обычную проверку WORKSPACE_SETUP. Удаление локальной записи допускается только для архивного проекта с совпавшим project_id.

## Проверка реализации

T025 реализует хранение и миграцию архива. Удаление папок и экран настроек выполняются последующими задачами активного плана. Окончательные проверки сборки — VERIFICATION.

## Удаление папки (T026)

Локальный сервис выдаёт одноразовый предпросмотр: точный путь, имя, число сессий, число файлов и размер содержимого. Подтверждение требует точного имени проекта. Перед удалением повторно проверяются project_id, корневая папка и отпечаток дерева. Изменения после предпросмотра требуют нового подтверждения. Отмена аннулирует предпросмотр.

Запрещены корень диска, домашняя папка, приложение, его данные и локальный MCP, пересекающиеся зарегистрированные workspace, подменённые корни и вложенные точки монтирования. Символические ссылки внутри проекта удаляются как ссылки; их внешние цели сохраняются. Если папка уже отсутствует, подтверждение очищает только локальную историю.

После подтверждения записывается локальный журнал; папка переименовывается рядом в уникальный временный каталог и удаляется. Повторный запуск завершает подтверждённую операцию с проверкой идентичности. Новая папка на прежнем пути не удаляется. При ошибке записи история остаётся архивной, а журнал позволяет повторить очистку. До завершения операции возврат в активные блокируется.

Удаляются все локальные сессии выбранного workspace, их URL, тексты попыток, записи в миграционных копиях списка и строки диагностики проекта. Общий профиль входа в ChatGPT сохраняется. Сервис не обращается к ChatGPT и не удаляет облачные разговоры.
