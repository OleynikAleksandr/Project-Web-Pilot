# Архив проектов

## Пользовательский контракт

Шестерёнка справа от «Подробностей подключения» открывает настройки с архивом workspace. Архивирование из меню проекта убирает его из активного списка и сохраняет папку, план, все сессии и выбранный разговор. Архив — состояние Web Pilot; статусы Workflow Kit не меняются.

В настройках пользователь выбирает архивный проект. «Вернуть в активные» возвращает его дерево без автоматической отправки нового контекста. «Удалить с диска…» открывает отдельное подтверждение с точным путём, размером и числом локальных сессий. Удаление должно быть явно подтверждено и затрагивать только выбранную папку и её локальные записи. Чаты в аккаунте ChatGPT остаются: пользователь исключил их удаление из задачи.

## Хранение

SchemaVersion 3 добавляет archivedAt к workspace. Старые форматы 1 и 2 мигрируют с точной локальной резервной копией. Все существующие проекты начинают активными. Архив сохраняет sessions[], selectedSessionId, expanded, названия, URL и попытки отправки. При архивации выбранного проекта selectedWorkspace очищается; запоздалые обновления его сессий отклоняются.

Изменения настроек сериализованы и становятся видимыми только после успешного атомарного сохранения. Ошибка записи сохраняет прежнее состояние. Архивирование и возврат не требуют доступности папки; открытие после возврата выполняет обычную проверку WORKSPACE_SETUP. Удаление локальной записи допускается только для архивного проекта с совпавшим project_id.

## Проверка реализации

T025–T027 реализуют хранение, удаление и экран настроек. Изолированный Electron smoke проходит реальные кнопки и локальные IPC: архив, возврат, прежний чат, отмену и подтверждённое удаление собственного временного workspace. Окончательные проверки macOS-сборки — VERIFICATION.

## Удаление папки (T026)

Локальный сервис выдаёт одноразовый предпросмотр: точный путь, имя, число сессий, число файлов и размер содержимого. Подтверждение требует точного имени проекта. Перед удалением повторно проверяются project_id, корневая папка и отпечаток дерева. Изменения после предпросмотра требуют нового подтверждения. Отмена аннулирует предпросмотр.

Запрещены корень диска, домашняя папка, приложение, его данные и локальный MCP, пересекающиеся зарегистрированные workspace, подменённые корни и вложенные точки монтирования. Символические ссылки внутри проекта удаляются как ссылки; их внешние цели сохраняются. Если папка уже отсутствует, подтверждение очищает только локальную историю.

После подтверждения записывается локальный журнал; папка переименовывается рядом в уникальный временный каталог и удаляется. Повторный запуск завершает подтверждённую операцию с проверкой идентичности. Новая папка на прежнем пути не удаляется. При ошибке записи история остаётся архивной, а журнал позволяет повторить очистку. До завершения операции возврат в активные блокируется.

Удаляются все локальные сессии выбранного workspace, их URL, тексты попыток, записи в миграционных копиях списка и строки диагностики проекта. Общий профиль входа в ChatGPT сохраняется. Сервис не обращается к ChatGPT и не удаляет облачные разговоры.

## Экран настроек (T027)

Шестерёнка стоит внизу справа от «Подробностей подключения». Экран показывает все архивные проекты с датой и числом сессий; выбор раскрывает точный путь и действия. В активном списке меню ⋯ → «Перенести в архив» доступно у каждого workspace. Закрытие настроек возвращает список проектов.

Архивирование выбранного workspace отменяет локальный сценарий передачи контекста и открывает главную ChatGPT. Другой активный workspace продолжает работу. В настройках автоматическая передача приостановлена; возврат проекта не выбирает его и не отправляет сообщение. Последующее открытие восстановленного проекта возвращает его выбранную сессию. Попытка открыть архивную папку направляет в архив, без скрытого восстановления.

Кнопка удаления становится доступной только после ввода точного имени. При изменившейся папке открывается возможность нового предпросмотра; при прерванном подтверждённом удалении доступно «Повторить очистку». Архивные записи передаются интерфейсу без текстов сообщений, а все действия разрешены только локальному sidebar, не странице ChatGPT.

## Оформление в Settings (T030)

В верхней части того же экрана Settings добавлен раздел «Оформление» с двумя явными вариантами: «Светлая» и «Тёмная». Выбор относится к оболочке Project Web Pilot — левому сайдбару и нативной верхней панели окна. Настройка темы самого ChatGPT Web остаётся внутри ChatGPT и не изменяется действиями Web Pilot.

## Отдельное окно архива — scope 002

Settings больше не отображает сам список архивных workspace. В нём находится кнопка «Архив проектов», которая создаёт либо фокусирует отдельное локальное окно. Окно не загружает удалённый контент и получает только специализированный archive IPC.

Список поддерживает множественное выделение: обычный клик заменяет выбор одной строкой, Shift выбирает диапазон от последней опорной строки, Command/Ctrl переключает отдельный проект без сброса остальных. «Вернуть в активные» и «Убрать из списка» применяются ко всему текущему выделению.

«Убрать из списка» удаляет запись workspace из локального `workspaces.json`, включая сохранённые локальные связи сессий, но не читает и не меняет папку проекта и не обращается к ChatGPT. Повторное подключение той же папки создаёт для Web Pilot новую локальную запись. Физическое удаление остаётся отдельным действием для одного выбранного проекта и использует существующий preview, точный путь и подтверждение именем.

### Атомарное массовое забывание — scope 002 / T002

Массовое «Убрать из списка» выполняется одной мутацией `WorkspaceSessions`: весь набор `workspace/projectId` проверяется до записи. Если хотя бы одна запись больше не архивная либо сменила идентичность, ни один выбранный проект не исчезает. Метод не обращается к папкам проектов; одиночное забывание использует тот же путь.

### Локальное окно архива — scope 002 / T005

Main создаёт единственный `BrowserWindow` архива; повторное открытие только показывает и фокусирует существующее окно. Страница загружается из локального `archive.html`, использует отдельный preload без Node integration и имеет собственную проверку sender URL. Главный store остаётся единственным источником архива, а `publish()` рассылает актуальную проекцию одновременно sidebar и окну архива.

### Multi-select и действия — scope 002 / T006

Окно архива использует обычный desktop selection model: простой клик оставляет одну строку, Shift выбирает непрерывный диапазон от anchor, Command/Ctrl переключает отдельную строку. Restore и «Убрать из списка» отправляют main весь выбранный набор; delete доступен только при единственной строке и показывает прежний preview с вводом точного имени. Settings больше не рендерит список: там остаётся только кнопка «Архив проектов…».

## Проверка scope 002

Интеграционный smoke создаёт несколько архивных записей, проверяет Shift-диапазон и Command multi-select, массовый restore и forget, сохранность папки после forget и повторное локальное подключение. Физическое удаление отдельно проходит preview, отмену и точное подтверждение для одного проекта; соседние архивы остаются нетронутыми.
