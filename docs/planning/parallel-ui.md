# Исполнители и время — рабочий контракт T007

В дереве основного проекта группа «Исполнители» подписана названием сессии происхождения. Каждый ряд показывает ID/название задачи, worktree, Chat/Work, текстовое состояние и время работы/ожидания. Клик использует обычный защищённый selectSession с папкой конкретного worktree. Основная сессия не владеет планом; связь нужна для происхождения настроек и показа группы. Завершённые чаты остаются доступны.

Состояния различают наблюдаемую работу, паузу, неподтверждённую команду, подготовку окружения, готовый коммит с продолжающимся ответом, готовность к слиянию, интеграцию, конфликт и проверенное завершение. Idle не интерпретируется как вопрос пользователя. Без живого наблюдения показана неопределённость. Основная панель при выборе исполнителя показывает parent plan, не локальное DONE; если parent ещё не прочитан, прогресс не объявляется подтверждённым.

Кнопки «Выполнить доступные задачи» и «Передать исправление основному агенту» обращаются к узким IPC из T006. Выдача возвращает управление панели сразу, подготовка и ошибки отображаются событиями; можно просматривать другие чаты. Во время интеграции новые выдачи недоступны.

ExecutorTimer отдельно суммирует время наблюдаемого busy и ожидания при открытом приложении. Переходы и пятесекундные отсчёты часов сохраняют totals в сессии. При restart восстановлены только подтверждённые totals: закрытый интервал не добавляется и активность не выдумывается. При потере страницы часы приостановлены; после интеграции остановлены. UI обновляет только часы, без запросов Git/DOM/сети. Прежний AgentTimer обычных сессий сохранён.

Проверки: JSDOM настоящего сайдбара (группа, статусы, время, адреса кнопок, локальное DONE против parent), проекция без текста беседы, часы с restart и разделением ожидания. Живые проверки интерфейса остаются пользователю.
