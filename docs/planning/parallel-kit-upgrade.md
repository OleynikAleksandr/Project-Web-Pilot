# Переход Kit 1.6.4 → 1.7.0

Пакет, константа VERSION и lockfile используют 1.7.0. Установщик поддерживает выпущенную 1.6.4 и прежние поддержанные версии. Переход не включает скрытого преобразования последовательных планов в параллельные: отсутствующие поля сохраняют прежнее поведение.

Перед записью установщик отказывает при локальном assignment.json, integration.json или незавершённом родительском назначении. Контракт активного worktree зависит от унаследованного runtime; обновлять его наугад нельзя. Отказ сохраняет runtime, manifest, HEAD и журнал назначения. Остальные проверки индекса, Git, существующих служебных файлов и занятых путей сохраняются.

Fixture извлекает неизменяемый выпущенный runtime 1.6.4 из истории Git, начинает задачу, обновляет через install --update, завершает её новым runtime и начинает следующую. Отдельно сохраняется аналогичный переход с 1.5.6 и существующее ревью 1.6.3. Исходником остаётся packages/workflow-kit; локальную установленную копию обновляет только установщик.
