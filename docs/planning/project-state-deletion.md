# Удаление состояния проекта и повторное использование папки

## Результат
Окончательное удаление проекта через Web Pilot удаляет его локальные записи, разрешения AutoPlan, журналы назначений и продолжений, копии и диагностику. Связанные исполнители и их worktree очищаются только после проверки принадлежности. Архивирование сохраняет состояние. Облачные чаты и профиль входа не удаляются.

Новый проект с другим project_id в той же папке не наследует разрешений, назначений и состояния плана. Существующие подтверждённые назначения того же проекта и защита UNKNOWN сохраняются. Панель показывает единое состояние назначения, без ложного переключения текущей задачи на ожидающую.

## Проверка
Регрессия удаления через реальные IPC на временном проекте: остатки во всех хранилищах отсутствуют, соседний проект сохранён, повторная папка и scope получают новое назначение. Прерывание очистки восстанавливается журналом без удаления подменённой папки. Unit проверяет identity, старые журналы и проекцию UNKNOWN. Живая пользовательская приёмка и native Windows остаются отдельными проверками.

## Границы и выпуск
Один пишущий агент, последовательный план: изменения очистки, identity и IPC тесно связаны. Модельные агенты и Computer Use не используются. После актуализации документов — одна парная сборка 0.6.109, установка готовой macOS-копии и публикация обеих платформ и main на GitHub. Предыдущий план закрыт по прямому поручению пользователя; это не объявляет непройденные платформенные проверки успешными.
