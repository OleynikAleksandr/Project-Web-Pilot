# Восстановление параллельного исполнения

При запуске приложение сверяет сохранённый журнал с текущим планом, назначениями Kit и Git. Сохранённая отметка INTEGRATED сама по себе не доказывает завершение: требуются проверенная история main, точные source и integration SHA. Уже совершённый коммит с незавершённой финализацией продолжает только существующий журнал Kit. Неизвестный merge не запускается повторно.

Зарезервированное назначение, отсутствующее в Kit после сбоя, остаётся UNKNOWN и занимает место в лимите. Новый ID для той же задачи не создаётся. Подготовка известного worktree может продолжиться под прежним ID после явного запуска или при AutoPlan ON. Результат неизвестной отправки и потерянная связь с сохранённой сессией требуют проверки пользователем; автоматического нового чата или Send нет.

Восстановление скрытой страницы требует точного соответствия task/assignment/scope/origin/workspace и сохранённого адреса разговора с доказательством начатой отправки либо ручного старта. Выбранная в панели сессия не подменяет адресата. Ошибка одного исполнителя блокирует его интеграцию и зависимые задачи; остальные назначения сохраняются. «Повторить сверку» перечитывает состояние без отправки сообщения и без повторного создания назначения.

Однократная автоматическая перезагрузка, ручной Stop и срок паузы rate-limit сохраняются в своей сессии. Перед перезагрузкой сохраняется факт использования попытки. После перезапуска неизвестный Send и черновик по-прежнему блокируют перезагрузку. Повтор пользователем остаётся явным действием текущего чата. Неизвестная отметка активности MCP не удаляется автоматически: отсутствие процесса само по себе не доказывает исход команды.

При сохранённом незавершённом merge без доказанного коммита очередь показывает состояние Kit. Исправление и integration:continue выполняются в основной сессии; неизвестный исход проверяется по Git и журналу, без reset или автоматического повторного merge. Историческая проверка интеграции использует контракт задачи на момент её принятия, поэтому последующее закрепление ссылок на документацию не отменяет доказательство уже принятого результата.
