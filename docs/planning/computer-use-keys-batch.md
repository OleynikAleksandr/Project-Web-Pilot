# Computer Use: имена клавиш, пакет действий и подсказки канала — релиз 0.6.85

Поручение пользователя 04.10.2026 после проверки Computer Use через VPS и встроенными средствами Work: внести найденные правки, чтобы не забыть, без ухудшения текущей работы.

## Что показала проверка

- Встроенно (Work, `node_repl` + `@oai/sky`) модель пишет имена клавиш X11 (`asterisk`, `equal`) по инструкции Computer Use. Через MCP Web Pilot модель этой инструкции не видит и передаёт символы (`*`), а `computer_key_press` отправлял их в sky как есть → `keyNotFound("*")`.
- `equal` даёт `+`, `Escape` не очищает Калькулятор, `type_text` портит кириллицу — так же и встроенно; это поведение sky/приложения. MCP печатает через `paste` — правильно.
- Главная разница в скорости — число ходов модели: встроенно несколько действий выполняются одним вызовом, через MCP каждое нажатие — отдельный вызов инструмента и ход модели (1–2 с).
- Интерфейс канала: на чужом Mac без своего сервера подпись ссылается на репозиторий vps-server; при смене канала не сказано, какой плагин включить в ChatGPT.

## Результат

1. `computer_key_press` и `computer_hotkey` переводят символы в имена клавиш X11 (`*` → `asterisk`, `=` → `equal`, `+` → `plus` и т. д.); прежние имена (`Return`, `Escape`, `asterisk`, буквы, цифры) работают как раньше.
2. Новый инструмент `computer_actions`: последовательность действий в активном приложении одним вызовом — `key`, `hotkey`, `text` (вставка), `click`, `scroll`, `wait`. До 50 действий; выполняются по порядку одним вызовом `node_repl`; при ошибке остановка, в ответе — результат каждого выполненного действия. Существующие инструменты не меняются.
3. Подписи канала VPS нейтральные: «Свой сервер не настроен» без ссылок на vps-server.
4. Под переключателем «Подключение ChatGPT» — подсказка, какой плагин включить в ChatGPT для выбранного канала.
5. Релиз **0.6.85**: версия → DOCS → парная сборка → установка в `/Applications` → GitHub Release и синхронизация `main`.
