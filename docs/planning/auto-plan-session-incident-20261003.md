## Требуемое исправление и проверка T004

Сначала уточнить доступные DOM machine ID и порядок сообщений для Work, затем заменить количественный fallback. Один и тот же ответ должен сохранять идентичность при rerender/reload/restart, новый ответ — отличаться даже при неизменном числе узлов. Нельзя лечить это очисткой реального ledger, случайным ID при каждом snapshot, хешем текста или повтором Send по таймеру. Старые checkpoint и неизвестный исход отправки требуют безопасной совместимости.

Диагностика должна различать ID/его источник без записи текста беседы.
