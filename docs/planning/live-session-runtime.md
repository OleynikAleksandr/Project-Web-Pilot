# Живые сессии — рабочий контракт T005

Дополнение к [спецификации](parallel-execution-spec.md). При DOCS выпуска переносится в контракт сессий.

`SessionRuntimes` на уровне приложения хранит отдельные WebContentsView, PageState, Composer, ContextSession, таймер и ConversationRecovery. Страницы используют общий профиль ChatGPT; фоновые страницы не ограничиваются backgroundThrottling. Ключ включает workspace/session и, при наличии, назначение/задачу. Наблюдатель проверяет WebContents/mainFrame и актуальный документ прежним защищённым мостом.

Выбор чата вызывает show: предыдущее представление снимается с contentView, его работа и обработчики сохраняются. Возврат к уже открытому URL не вызывает loadURL и не отправляет контекст снова. Навигация, её epoch и отмена доставки принадлежат конкретной сессии. Запоздалые результаты readiness отбрасываются по ревизии этой сессии. Настройки цвета и видимости инструментов применяются к живым страницам.

Контроллер использует узкий sessionStore с неизменным адресом сессии. Фоновое сохранение attempt и привязка chatUrl требуют явного background; обычные UI-методы сохраняют прежнюю проверку выбора. Запись в чужую, удалённую или архивную сессию запрещена. Проекция workspace/session не меняет выбранную строку.

show/hide не запускают, не останавливают и не уничтожают сессию. release — отдельная операция; без force она отказывается уничтожать страницу с активной генерацией, доставкой или командой Composer. Подписки снимаются при release. Закрытие всего приложения явно освобождает реестр, не останавливая независимые службы MCP. Контроллер не хранит BaseWindow; будущий перенос той же страницы в другое окно не требует нового чата или Send. Кнопки detach и дополнительные окна не реализованы.

Unit-тесты проверяют независимость страниц и адресации, сохранение контроллера/таймера при переключении и переносе представления, отказ release при работе и позднее завершение навигации. Electron TEST FIXTURE проверяет реальные разные WebContents и события скрытой страницы. Это не живая приёмка ChatGPT и не проверка native Windows.
