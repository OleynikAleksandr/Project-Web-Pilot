# Автовыполнение текущего плана короткими ответами

## Результат
По поручению 29.09.2026 карточка текущего плана получает явный режим «Автовыполнение» для выбранного сохранённого разговора Chat или Work. Он отправляет начальную инструкцию агенту, затем только точное «Продолжай». Продолжение допускается для текущей незавершённой работы, а не только следующего пункта. При включении читается фактический checkout-план: существующие DONE не повторяются и не считаются новым событием.

Агент завершает ответ после одной микрозадачи и её подтверждённого коммита либо на безопасной промежуточной точке, не подделывая DONE. Длительная локальная команда может продолжаться в фоне; агент сохраняет её идентификатор и при возобновлении читает результат. Принудительный Stop по времени не применяется: он мог бы оборвать коммит или сборку.

Последняя строка итогового ответа — «Готов продолжать.», «Нужен ваш ответ.» либо «План завершён.». Это узкий договор с агентом; текст исходников, цитаты и блоки кода не являются командой. Наблюдатель передаёт только тип окончания и счётчики, не содержимое диалога. Ответ без признака контрольной точки требует проверки пользователем.

## Условия Send
Ответ завершён, выбран тот же scope/session/document, нет ошибки/Stop/ручного ввода, актуальный план доступен и не находится в подготовленной Git-транзакции. В незавершённом плане разрешено продолжать текущую IN_PROGRESS задачу без нового коммита. Все DONE, включая DOCS, считаются окончанием только при чистом plan-файле и отсутствии transaction journal. Пустой/NONE/BLOCKED план не запускается. Один ответ порождает не более одной отправки. Три контрольных ответа без изменения плана приостанавливают цикл.

Перед click повторно проверяется состояние плана. После click нет ожидания поиска сообщения и повторного Send при неопределённом исходе. Черновик пользователя не очищается. Ручной Stop, ввод и вопрос агента приостанавливают цикл до нового отправленного сообщения пользователя в том же документе. Оно возобновляет ранее включённый режим без дополнительного Send. Агенту прямо разрешено задавать вопросы и ждать ответа. Явное выключение кнопкой, смена документа/разговора/scope, ошибка или перезапуск отключают режим; нужна новая активация.

## Отсутствие продвижения и восстановление
Однократный сторожевой таймаут 3 минуты отслеживает отсутствие наблюдаемых изменений ответа. Счётчик текстовых изменений передаётся не чаще раза в 5 секунд во время потока; декоративная анимация не считается продвижением. Он сообщает подозрение и приостанавливает автоматизацию, не объявляет серверный ответ завершённым и не нажимает Stop. Терминальная ошибка потока использует существующее ограниченное восстановление того же URL; после восстановления режим включается явно. Ручной Stop запрещает автоматическое восстановление. HTTP 429 требует паузы; никакой бесконечной перезагрузки.

## Запуск и проверка
В карточке плана нажать «Автовыполнение» при открытом свободном сохранённом разговоре. Нативный Stop останавливает текущий ответ; новое сообщение пользователя возобновляет включённый режим. Кнопка «Выключить автовыполнение» отключает режим полностью. Предусмотрены Node-тесты состояния и Electron smoke через sidebar/реальный preload/composer с изолированной страницей Chat/Work. Проверяются частичный план, IN_PROGRESS, все DONE до старта и перед Send, подготовленная транзакция, дубли событий, вопрос, черновик, ручной Stop, смена чата, перезагрузка и неопределённый Send. Установленная копия проверяется отдельно. Живую устойчивость ChatGPT пользователь проверяет на реальных задачах; fixture не доказывает устранение серверных зависаний.
