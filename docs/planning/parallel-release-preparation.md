# Подготовка выпуска

Следующая свободная версия приложения — 0.6.104, пакет Workflow Kit — 1.7.0. Тег и локальные каталоги поставки этого номера до подготовки отсутствовали. Root package.json и lock согласованы; evidence проверок актуализированы через config:apply.

Проверки исходников выполняет Kit перед коммитом задачи версии: unit-all, electron-smoke, codex-tools-live, kit-check. После DOCS отдельная delivery-задача один раз собирает обе платформы; установка и публикация используют готовую поставку без пересборки. Живая приёмка остаётся открытой по подготовленному протоколу.

Проверка codex-tools-live обнаружила установленный Codex 0.162.0 вместо закреплённого 0.161.0. Сверены официальные файлы тегов openai/codex: shell_spec.rs меняет только внутреннее allow_login_shell → include_login_parameter в двух местах; параметры JSON не изменены, view_image_spec.rs и apply_patch.lark побайтно прежние. Lock и evidence обновлены под фактическую версию; прямой App Server без модельных ходов проверяется в unit-all.
