# Проект

Кратко зафиксируйте поручение пользователя, ожидаемый результат, основной сценарий, способ запуска и ограничения. Ясное поручение не требует дополнительного согласования. Пока поручения нет, документ остаётся заготовкой.

Подробности храните в одном профильном документе по ссылке из docs/DOCUMENTATION_INDEX.md. Не дублируйте его здесь. Для программных задач по умолчанию готовится локальный работающий прототип; подготовка к распространению требует отдельного поручения.
