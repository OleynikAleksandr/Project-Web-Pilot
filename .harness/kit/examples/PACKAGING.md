# Упаковка Electron-приложения

Упаковка берёт только runtime-файлы. Пример electron-builder:

```json
{"build":{"files":["dist/**","package.json","!**/.harness/**","!**/.git/**","!**/.codex/**","!**/.env*","!**/auth.json","!**/settings.json","!scripts/workflow*"]}}
```

Проверьте production-зависимости отдельно: electron-builder включает их сам. Не копируйте целиком каталог проекта в Resources. В готовом артефакте недопустимы настройки приложения, планы, runtime Workflow Kit, пользовательские сессии и учётные данные.

В scripts/check-package.mjs используйте listPackage из @electron/asar для ФАКТИЧЕСКОГО app.asar и verifyPackageEntries из этого каталога. Передайте список и конкретный allowlist runtime-путей; стандартный список — package.json, dist/, node_modules/. Пример:

```js
import {listPackage} from '@electron/asar';
import {verifyPackageEntries} from '../.harness/kit/examples/verify-package.mjs';
const entries = listPackage('release/mac-arm64/Browser.app/Contents/Resources/app.asar');
verifyPackageEntries(entries);
if (!entries.includes('/dist/main.mjs')) throw new Error('Missing entry point');
```

Это проверяет архив, но не доказывает запуск. Отдельно осмотрите app.asar.unpacked и extraResources, если они используются: приватные файлы могут находиться вне архива. На macOS установите .app через ditto с сохранением символических ссылок, затем проверьте именно установленную копию: запуск, URL без схемы, Enter, Go и смену страницы. scripts/check-installed.mjs должен завершаться ошибкой при провале утверждений, а не просто открывать приложение. Вид проверки installed и evidence описывают проверяемую копию и сценарии; результат hook сохраняет вместе с коммитом. Ручная приёмка пользователя остаётся отдельной.

## Локальный прототип

До первой сборки выбери выходной каталог и исключи его воспроизводимое содержимое из Git, сохранив исходники, ресурсы, lock-файл и пользовательские правила. В приведённом выше примере артефакт находится в release/ — этот фактический каталог должен быть исключён заранее. Не применяй универсальное исключение папок только по имени; .gitignore не действует на tracked-файлы.

Локальная тестовая сборка не должна автоматически выбирать пользовательский сертификат. Для electron-builder явно укажи `"mac":{"identity":null}`. Подпись сертификатом, нотарификация и распространение относятся к отдельному запросу пользователя. Техническая подпись без сертификата, необходимая платформе для запуска, допустима.

Готовь проверку до первой сборки. Сценарий installed должен проходить через настоящий интерфейс; прямой вызов внутренней navigate не подтверждает Enter/Go, а canGoBack не доказывает переход назад. Сохраняй ошибки preload/renderer вместе с результатом. Разделяй установку и проверку, чтобы повторная проверка не переустанавливала приложение. Не повторяй успешные проверки вручную, если их сразу выполнит commit на том же состоянии.
