# Начало работы

Новая сессия начинает работу с recovery capsule Workflow Kit. Capsule уже содержит Workflow Core, текущий todo-plan и обязательную навигацию проекта: `docs/architecture/OVERVIEW.md`, `docs/MODULES.md`, `docs/DOCUMENTATION_INDEX.md`. Для активного scope к ним добавляются релевантные specification/planning documents, рабочее состояние и только необходимые dependency diffs. Большой WORKFLOW.md и исторические документы читать целиком не требуется.

## Порядок

1. Использовать доставленный capsule; если его нет — `./scripts/workflow recover --format text`.
2. При `NONE` не начинать проект заново: обсудить с пользователем следующий этап на основании общей структуры и индекса документации.
3. Новый запрос сопоставить с существующей частью проекта в `docs/MODULES.md`; если её нет — сначала создать и согласовать подходящий specification/planning document.
4. Для программного модуля согласовать facade, входы/выходы, границы и инварианты; для непрограммного проекта использовать естественную предметную структуру.
5. Только после согласования создать/уточнить todo-plan. Каждый рабочий plan завершается задачей `DOCS` — «Актуализация всех документов проекта».
6. Перед изменением начать task, после микрозадачи выполнить управляемый commit и применимые проверки.
7. После `DOCS` предъявить результат пользователю на приёмку. Архивирование требует отдельной прямой команды пользователя.

`docs/architecture/OVERVIEW.md` — компактная общая карта проекта, `docs/MODULES.md` — карта его самостоятельных частей, `docs/DOCUMENTATION_INDEX.md` — полный пополняемый индекс. Подробная история остаётся reference-only.
